# أكلني | Eklni

**Eklni Nutrition Platform** — منصة التغذية الذكية | Smart Nutrition Platform

منصة تغذية رياضية مصرية للرياضيين، وخصوصًا السباحة وسباحة الزعانف «مونو». بتقدم:
- هدف وزن آمن وجدول زمني.
- احتياج طاقة وماكروز بمعادلات مذكور مصدرها.
- خطة وجبات أسبوعية من أكل مصري حسب تفضيلات اللاعب ومواعيد تمرينه.
- خطة بطولة.
- ترطيب ومعدل تعرق.
- فحص صحي مبدئي بعلامات إحالة.
- متابعة أسبوعية مع تعديل تكيفي، وأي تعديل محتاج موافقة المستخدم.

> **الحالة: نموذج أولي قيد التطوير، وغير جاهز للإنتاج.** القيم الغذائية للأطعمة اتراجعت (2026-10-22) من أخصائي تغذية (أحمد ربيع حسين، بإقرار)، واتحدثت لأحدث قيم USDA. قواعد الحساب والفحص الصحي لسه محتاجة مراجعة مختص، ولسه ما اتعملش اختبار أمني مستقل. التطبيق لا يشخّص أي حالة ولا يغني عن طبيب أو أخصائي تغذية رياضية.

## التشغيل

يتطلب Node.js 22.5 أو أحدث، بدون مكتبات خارجية.

```bash
cp .env.example .env   # اختياري
npm start              # http://localhost:3000
npm test               # 181 اختبارًا
node scripts/nni-compare.js   # مقارنة قيم التطبيق بجداول المعهد القومي للتغذية (من غير تعديل)
python3 scripts/usda-extract.py <FNDDS Ingredient Nutrient Values.xlsx> [<Foundation CSV folder>] && node scripts/usda-compare.js   # مقارنة بملفات USDA الرسمية
npm run verify-fixes   # كل إصلاح مقابل اختباراته
npm run check-config   # فحص إعدادات الإنتاج
npm run owner -- grant you@example.com   # منح صلاحية مالك المنصة (من السيرفر بس)
npm run backup         # نسخة احتياطية متسقة
npm run review-foods -- template > review.csv   # مراجعة القيم الغذائية بشريًا
node demo/build.js     # نسخة تجريبية تعمل في المتصفح فقط (demo/aklny-demo.html)
```

## الميزات

| المجال | ما يفعله |
|---|---|
| الهدف والجدول الزمني | معدل خسارة شخصي (سقف 1%/أسبوع، ويقل حسب النحافة والحمل التدريبي والمنافسة والعمر ومرحلة الموسم)، تاريخ تقديري وسيناريوهات |
| الطاقة | RMR بالأولوية: المقاس ← Cunningham (لو الكتلة الخالية من الدهون موثوقة) ← Mifflin-St Jeor. التمرين بـ MET صافي. العجز ≤25%، وتوافر الطاقة ≥30 مع تصنيفه |
| الأمان | فحص صحي مبدئي. أي علامة حمراء يعني سعرات ثبات بدون عجز مع رسالة إحالة، إلا لو البالغ أقر إنه بيكمّل على مسؤوليته (مش متاح مع التقيؤ أو الحمل أو للقُصّر). اللاعب من 12 لـ 17 سنة على الثبات إلا لو ولي أمره المربوط بالحساب وافق، وساعتها العجز ≤15% والمعدل ≤0.5%/أسبوع (قاعدة محتاجة مراجعة مختص) |
| الترطيب | معدل التعرق من الوزن قبل/بعد الحصة والسوائل. تحذير عند فقد ≥2% أو زيادة الوزن (إفراط في الشرب). تعويض 125–150%. فحص الصبح (وزن/بول/عطش) |
| المغذيات الدقيقة | RDA وUL للحديد والكالسيوم وفيتامين د حسب العمر والجنس. الحديد وفيتامين د في الخطة حد أدنى مع نسبة تغطية البيانات |
| خطة الأسبوع | مواعيد وجبات حسب الصحيان والنوم والتمرين (حتى حصتين في اليوم)، أنواع البروتين المفضلة، صيامي، رمضان، وجبة حرة، مشروبات وسناكس مع تعويض، صوصات، وسجل نسخ مع استرجاع |
| البطولة | تحميل كربوهيدرات، جدول يوم السباق، قواعد ما بين السباقات، التعافي |
| الوصفات | 307 وصفة أصلية بالجرام لكل حصة، منها 32 مشروب؛ الصوصات بتتضاف بس لما اللاعب يطلبها |
| التقارير | تقرير للطباعة/PDF موقّع أسفل كل صفحة «ك/ أحمد ربيع»، وملف CSV |
| المصادر | سجل مراجع داخل التطبيق، وملخص جودة بيانات الأطعمة |
| الاشتراك | شهري (بالشهور الميلادية)، فترة تجريبية قابلة للضبط، كل الأدوات بتتقفل على السيرفر بعد الانتهاء (تنزيل البيانات CSV بيفضل متاح)، لوحة للمالك لتسجيل الدفع والتمديد والإلغاء |
| ملف التغذية PDF | **زرار تنزيل .pdf مباشر**: من السيرفر بنص حقيقي لو `EKLNI_CHROMIUM` متضبط، أو بيتعمل في المتصفح (الصفحات كصور) لو مش متضبط. ملف A4 فيه الأهداف وطريقة التغذية والسوائل و7 أيام بالمواعيد والجرامات وقائمة المشتريات، بتوقيع وشعار الأكاديمية |
| الدخول | بالإيميل وكلمة المرور، أو بحساب جوجل (Gmail) لما يتضبط `GOOGLE_CLIENT_ID` |
| رياضي أو لأ | الرياضي بيختار رياضته ومرحلة الموسم؛ غير الرياضي من غيرهم |
| سعرات مخصوصة | الشخص يكتب سعرات اليوم لمدة أقصاها أسبوع، في حدود الأمان |
| البيت | ربط أكتر من حساب في نفس البيت: الوجبات المشتركة بنفس الأطباق، والجرامات لكل واحد على حسب هدفه، وقايمة مشتريات للبيت |
| المشاركة | رابط للقراءة بس لخطة التغذية يتبعت واتس اب أو تليجرام أو إيميل، بموافقة ومدة وإلغاء |
| الرياضات | سباحة وزعانف «مونو»، جري، دراجات، تحمّل، جماعية، قوة، **سلاح، خماسي حديث، ثلاثي** |
| الأكاديمية والفريق | أدوار (مدير، مدرب، أخصائي، لاعب، ولي أمر)، أكواد دعوة، مشاركة البيانات الصحية بالموافقة، عرض لكل دور، سجل تدقيق |
